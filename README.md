# Focus

Focus — pet-приложение для управления личными и командными задачами и проектами: планирование задач с дедлайнами и приоритетами, работа в командах с приглашениями и ролями, учёт клиентов (для фрилансеров), статистика и отчёты с экспортом в Excel.

## Стек технологий

- **Backend:** Python, FastAPI, JWT-авторизация
- **База данных:** PostgreSQL (psycopg2)
- **Frontend:** чистые HTML/CSS/JS без фреймворков — статика отдаётся тем же FastAPI-приложением
- **Экспорт отчётов:** openpyxl (Excel-файлы с диаграммами)

## Структура проекта

```
plan/
├── back.py          # точка входа FastAPI-приложения, раздача статики, CORS
├── auth.py          # JWT-токены, хеширование паролей (bcrypt), валидация
├── database.py      # подключение к PostgreSQL
├── models.py        # Pydantic-схемы запросов/ответов
├── routers.py       # все API-эндпоинты (/api/...)
├── index.html       # главная страница приложения
├── login.html        # страница входа
├── register.html    # страница регистрации
├── script.js         # вся клиентская логика (SPA на чистом JS)
├── style.css          # стили
├── images/            # логотип и изображения
├── emoj/               # иконочный шрифт (themify-icons)
├── .env.example         # шаблон переменных окружения
requirements.txt          # зависимости Python
```

## Функционал

- Регистрация и вход по email/паролю (JWT, bcrypt)
- Два типа пользователей: обычный пользователь и фрилансер (разный набор функций)
- Проекты: личные и командные
- Задачи: приоритет, статус, дедлайн (дата и время), теги, назначение исполнителя
- Категории и теги задач
- Команды: создание, роли (менеджер/участник), приглашение и удаление участников
- Уведомления: приглашения в команду (принять/отклонить), напоминания о дедлайнах
- Клиенты (для фрилансеров)
- Статистика по задачам и проектам, экспорт статистики в Excel
- Отчёты по проекту/клиенту/команде за период с экспортом в Excel (таблицы + диаграммы)

## Установка и запуск

1. Создать и активировать виртуальное окружение:

   ```bash
   python3 -m venv venv
   source venv/bin/activate  # Windows: venv\Scripts\activate
   ```

2. Установить зависимости:

   ```bash
   pip install -r requirements.txt
   ```

3. Создать базу данных PostgreSQL:

   ```sql
   CREATE DATABASE taskflow_db;
   ```

   (структуру таблиц нужно создать самостоятельно по коду в `plan/routers.py`/`plan/database.py` — файла миграций в проекте пока нет)

4. Скопировать `plan/.env.example` в `plan/.env` и заполнить своими значениями:

   ```bash
   cp plan/.env.example plan/.env
   ```

   Переменные:
   - `DB_NAME`, `DB_HOST`, `DB_PORT`, `DB_USER`, `DB_PASSWORD` — подключение к PostgreSQL
   - `JWT_SECRET_KEY` — секретный ключ для подписи JWT-токенов (любая случайная строка, например `openssl rand -hex 32`)

5. Запустить приложение:

   ```bash
   cd plan
   uvicorn back:app --reload
   ```

6. Открыть в браузере `http://localhost:8000`.

## Известные ограничения / что дальше

- Нет файла миграций/схемы БД — структура таблиц восстанавливается по коду
- Нет автоматических тестов
- CORS настроен на несколько локальных адресов «про запас» — в проде список origin нужно сузить до реального домена
- Не реализовано восстановление пароля
